# 2026-10-22 fix2-g43: turret bosses, rocket turrets (audit wave 2)

Branch agent-fix2-g43 (from 806ed84). Files: engine/src/vehicles/{boss,gunnery,mod,mover,rocket_turrets}.rs,
docs/subsystems/vehicles.md, docs/original-bugs.md, playtest engine/playtests/vehicles_saucer_halt.json (new).
No other package had any of these addresses (git grep over agent-fix2-* and merge-wave2).

## What was learned

- The bosses' vt+0x228 is fn_00435250 (false) for the saucer, zeppelin and colossus: Q112Boss_Slot102 0x00435940 takes
  the plain path and fires through vt+0x194(0, 0, 1, 0), i.e. 0x004284e0 **without a target**: the shot goes from the
  emitter along its -Y (the weapon's slot 0x4f 0x004a1e90), aimed 1000 along it. No aim error and no homing; where the
  shots go is where the turret faces. The boss port had aimed each shot at the target with the AI aim error.
- The turret faces its target's ref_hit_00, or the 0x004580a0 lead point (from the target's position, speed +0x5c4 =
  450) when 0x004531e0 holds and shots left (+0x5b8) <= volleys fired (+0x5c0). Before the slerp its facing takes the
  aim direction's vertical part (fr.U(0x28) = fr.U(0x38)): the pitch follows at once, the yaw turns at 4 x dt.
- 0x00435b50's stop applies to the flying bosses too. On an IC path 0x00426630 (+0xa18 bit 0) holds, so the boss
  keyframes, zeroes its velocity and enters state 0x66, where the path clock +0xa20 stops (it only runs in state 0x64);
  the target gone, state 0x64 again. p_saucer has no stop_volley_count, so the saucers stop after 3 volleys; the
  zeppelins have 0 (never). 0x004577b0's argument is "keyframed", so 1 holds the body (no fall).
- A flying or halted boss ignores hit reactions (0x0042f8d0 "busy" through 0x00426630); the colossus's reactions stop
  its targeting and its gunner (0x00447400 skips both in states 0x12c..0x132) and end in state 0x10f (walking).
- Player vt+0x54 / vt+0x6c = Body_getPosition 0x00457930 = body + origin offset (+0x2dc): his origin (feet in the
  engine). The rocket turrets' ranges and the bud's aim use it; the sight rays go to ref_hit_00.
- The game clock 0x00604a98 is QPC time since start-up minus pauses, not level time: the "last seen = 0" blind fire of
  the rocket turrets cannot happen after a menu and a load.
- Every captain_rocket set in the shipped levels is dumb_fire 1, so a projectile's homing target (0x004a2010 vt+0x14c)
  changes nothing for the grunts' rockets or the bosses' missiles.
