## Done: Vulkan at parity, remaster outputs (steps 3 to 5)

- **Parity:** `[render] rhi=1 backend=vulkan` passes `tools/compare_backends.py` in menu, level, play and quit,
  with identical draw counts and image MAE at most 0.01. It is deterministic against itself.
- **Fixes that got there, each measured against D3D9:**
  - present parameters written back (the "disc error" screen)
  - x87 24-bit precision after CreateDevice
  - GetAvailableTextureMem 0xFFB00000
  - SetLOD
  - table fog by depth z
  - X8 alpha read as 1
  - zero-filled new resources
  - container semantics for texture surfaces: cube-face surface pointers were reused, so faces went to the
    wrong texture
- **Remaster outputs:**
  - RGBA16F back buffer with a present pass: `tonemap=none|aces`, `exposure`.
  - Motion attachment (RG16F, written only by depth-writing draws).
  - Debug views: `debug_view=depth|normals|motion`.
- **Debug views** (`tools/vk_debug_views.py [frame] [turn]` writes work/shots/debug_views.png):
  - Depth now uses the projection's _34. The game's camera is right-handed (_34 = -1). The old formula assumed
    _34 = +1 and showed black.
  - Normals face the camera.
  - The motion view scale follows `exposure`.
- **Motion vectors verified:**
  - Method: the new scripted mouse motion `[test] keys_frames=...,599:MOUSEX2` turns the camera, and block
    matching between frames 599 and 600 is compared with the vectors.
  - Result: median error 1.4 px over 60 points. The readback is quantised to 0.5 px.
  - The player character, which moves with the camera, reads 0 (frame 600, before the turn).
  - Script: `tools/vk_motion_check.py [frame] [turn]`.
- **Scene description** (`src/rhi/vulkan/vk_scene.*`):
  - Per-frame records of the 3D draws into the back buffer.
  - All of the game's 3D draws use its own vertex shaders. All 228 dumped vertex shaders write
    `oPos = r0 . c22..c25`. Correction (camera recon, docs/subsystems/camera.md): c22..c25 is the projection alone (Renderer_FlushTransforms 0x004fcc30) and r0 is the camera-space position (world*view at c42..c44) (`tools/vs_position_chains.py`: 8 shapes).
  - Vertex capture: a variant of each vertex shader writes clip positions to a storage buffer (vk_abi.h binding
    4, needs vertexPipelineStoresAndAtomics). The inverse of c22..c25 gives camera space (not world space), including skinned
    meshes.
  - `[render] vk_dump_scene=N` writes an OBJ. Checks: `tools/vk_scene_check.py`, then `tools/vk_scene_zcheck.py`.
  - Verified at play frame 600: 757 draws, 110k triangles. Z-buffered, they reproduce the depth buffer within its
    8-bit display step (median 1.2 units, step 1.18). All covered pixels match. The 3D viewport is letterboxed
    to 640x372 at y = 54.
- **Docs:** docs/renderer-interface.md (Vulkan section, remaster outputs) and docs/subsystems/renderer.md
  (new: the vertex shader constant layout and the camera).

## Remaster basics (docs/goals/remaster-basics.md), first pass

- **Recon:** five static agents wrote docs/subsystems/camera.md, ui.md, menus.md, decals-bodies.md and qol.md.
- **Correction:** c22..c25 is the projection alone; the view is folded into c42..c44 (Renderer_FlushTransforms
  0x004fcc30). So the scene capture gives camera-space positions, not world-space. The docs and comments were
  corrected. The corpus has 228 vertex shaders, not 456 (that count included a duplicate folder).
- **Tessellation (Vulkan):**
  - Phong tessellation of the skinned meshes, the ones whose vertex shaders read relative constants.
  - Normals come from running the shader's own position program again with the position input moved along the
    NORMAL input, so skinning applies to them.
  - Strips and fans are converted to patch lists in the uniform ring.
  - Levels follow screen-space edge length (default 6 px, at most 8).
  - Evidence: work/shots/tess_zoom.png. A shape factor of 4 visibly inflates the character, which proves the path
    is live.
- **Recovered (S2, compare identical in level and play):**
  - Camera_SetupProjection 0x0040f6e0
  - Decals_AllocatePool 0x00416150
  - Decals_Update 0x00416440
  - Corpse_CountDown 0x0042eba0
  - UiPass_Draw 0x00464460 (agent)
  - Each gets a null-by-default enhancement point. Renderer_SetGamma and Renderer_GetPixelWidth/Height got the
    same.
- **Camera:** Hor+, letterbox off (the patched constants are restored when switched back), FOV scale with zoom
  views excluded.
  - Measured at 1280x720: the original stretches the 3D view horizontally (it assumes a 4:3 monitor).
  - Evidence: work/shots/camera_grid.png.
- **HUD anchoring:** per UI object, a view-matrix change x' = k x - c z applied after the screen view. Anchors come
  from the object's ref (compass, weapon and ammo right; health left; crosshair centre; hit flashes stretch).
  Menu pages are centred.
  - Two findings on the game's matrices: they store one output coordinate per 4 floats (rows), and the flags word
    at +0x40 selects shortcuts (0x20 = general 4x4).
  - Evidence: work/shots/ui-anchor.png.
- **QoL:**
  - Quicksave and quickload keys call the pause menu's own functions. The game refuses to save in the harness:
    Game+0x568 bit 3 is set near the save-slot code (0x004a2db7), so it probably means "a save slot is chosen"
    (guess).
  - Mouse invert and per-axis sensitivity.
  - Master volume and output device, through DirectSoundCreate8 and IDirectSoundBuffer::SetVolume.
  - Brightness in the Vulkan present pass, which works in a window.
  - Borderless window and render scale.
  - Anisotropy, LOD bias and ACES switches.
  - Text scale, which also covers subtitles.
  - On Vulkan, DisplayBeforePresent (fps cap, fixed_dt_ms) never ran; HarnessOnFrame now calls it.
- **Settings registry** (hook/enhance/settings.h): every switch registers with a label, a range and a live-apply
  callback, for the Remaster page. With the defaults, every hook returns at once, so the original behaviour is
  unchanged.
- **Decals:** the manager counts 320 allocated decals per level, two level setups' worth. The early fade starts
  only when allocated - active + fading drops below 32, so the visible limit is about 288 (decals-bodies.md
  guessed 128).
