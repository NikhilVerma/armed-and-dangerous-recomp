Learned: the C++ comments in audio_01.cpp name the grunt voice sets wrong. The exe strings say: +0x484 bit 21 is gr1,
+0x488 bit 29 is GR3, otherwise gr2. So the Rust `voice_set` (0 = gr1, 2 = gr3, 1 = gr2) is right, and the three
"swap" findings were false. Bevy 0.20's `Entities::contains` can still be true for an entity that was just despawned.
Use a query (`followed.contains`) for "is the holder gone".
