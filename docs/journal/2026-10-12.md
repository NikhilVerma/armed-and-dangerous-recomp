## Next: crack-free, UV-safe tessellation (Phong-AEN), design from the 2026-10-12 research
Today: hand-rolled Phong (vk_tessellation.cpp). Split vertices (UV seams, hard edges, separate draws) crack, and some
rebuilt normals are garbage (stretched textures).
1. CPU weld in DrawTessellated: key = the POSITION element bytes (plus BLENDWEIGHT and BLENDINDICES when present),
   read from the mapped vertex stream at streamOffset + (base + idx) * stride + elem.Offset. Directed-edge map to find
   each edge's twin (j, i) in the neighbouring triangle. Patch = [i0 i1 i2, t01a t01b, t12a t12b, t20a t20b];
   boundary or non-manifold edges get twins = their own vertices and are flagged. Unit test on a 24-vertex cube.
2. 9-point patch list (vk_pipeline.cpp:345 patchControlPoints = 3 or 9 in the pipeline key; a 3-point fallback when
   POSITION is not readable).
3. TCS per edge: normals averaged across the seam, summed commutatively. Phong as a quadratic Bezier: edge point
   E_ij = (pi(P_j; P_i, Ni_e) + pi(P_i; P_j, Nj_e)) / 2, blended to the midpoint by shape x crease.
   Crease c = smoothstep(sharpCos, smoothCos, min(dot(N_i, N_i'), dot(N_j, N_j'))). Level 1 if c == 0, a boundary,
   or a bad normal (dot(N, faceN) < 0.2); else EdgeLevel. No per-patch "keep". Clamp |E - mid| <= 0.25 x edge length.
4. TES: sum u_i^2 P_i + 2 u_i u_j E_ij with `precise`, evaluated symmetrically; UVs and other varyings linear.
   Option tess_spacing = equal (integer levels, no swimming).
5. Normals: smaller OffsetPosition step (tessS about 1e-2 x position magnitude); decode SHORT4N / DEC3N.
6. Cache: index cache key + base + stream identity + VulkanBuffer::generation (bumped on writable Lock); 36 B per
   triangle; maybe raise kTessBuffer to 128 MB.
Sources: PN-AEN (McDonald & Kilgard 2010); Dudash GDC12 "My Tessellation Has Cracks"; Boubekeur & Alexa 2008.
