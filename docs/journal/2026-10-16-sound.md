# 2026-10-16: B17, the sound divergences the oracle found (agent-sound)

Branch agent-sound (from wip/full-decomp 5383198, merged up to the startfix merge). Remaster built in
engine/target-wt-sound; remaster-side oracle runs with `ORACLE_OUT=work/oracle-sound` (the originals' traces copied
from work/oracle), every run --background.

## Done (cause / fix / evidence)

- Pub loop `amb_pub_exterior_lp` (18 levels), oil pumps, world ambient loops: they played (AND_SOUND_LOG: t = 0.000)
  but were not reported. The bank's list was switched on in the trace system (Last) after the first frame's starts.
  Now oracle.rs `count` (First) switches it on. Matched on all pub levels.
- Reporting point: the original logs at StartVoice, before the driver refuses far streamed one-shots; the remaster
  logged only accepted voices. Now the list takes every play call (Part::Whole) at the driver's start; sequence bodies,
  outros and the music's next segment (Part::Piece) are not play calls. Zeppelin creaks: lev_5_m2 28 at load in both.
- `wpn_stig_mount` (lev_1_m4): the base turret's mount 0x0049bcc0 plays nothing (the stig gun's 0x00498f60 does).
  Removed from defence.rs `start`.
- `veh_bomber_lp` (lev_5_m5): fx_origin_start_lock (Object_LoadProperties) was read for bosses only. Now every
  placed object (vehicles/mod.rs `attach_start_lock_fx`; boss.rs's own copy removed). This also starts the pickups'
  fx_peasant, lanterns, monk glow and doormats.
- Sheep: SheepObject shares PenguinObject's methods (vtable diff: anims, screams, death lines only). The remaster
  played the template's default sheep_bleat in a loop. Now `Critter { species }` (level.rs) and `critters`
  (charanim.rs) do graze / scan / bleat. Sheep with a generic_txt that load after a start_in_turret mission
  (0x0044e600; instance order: lev_3_m4_bd 157..191 yes, lev_2_m4 / lev_5_m5 no) walk 5..10 s, one in two at load
  ((rand x 100) < 0x190000; the old "one in 5.3" comment was wrong). Bleat counts now match the original's
  (lev_2_m1 22 vs 20).
- Music: the remaster had only level 1's row of 0x005ce4e0. Now it picks the row by env_type (Game+0x2708). l2amb
  .. l5amb match at frame 60.
- Footsteps / impacts on every surface (water on lev_bonus_m3 was the listed case): the remaster used "snow"
  everywhere. The original takes the Havok material, which is named after the skin material (mesh +0x70, record
  +0x14). Fx_Create flag 0x800 then tries `<fx>_<token>` for each "_" token, then the object's material property,
  then the plain fx. Work done: the exporter writes "surface" per submesh (all 24 levels re-exported, identical
  otherwise), surface.rs `SurfaceMap` / `Surface::variant` / `StartSurfaceFx`, `Physics::surface` /
  `surface_below`. The callers are player.rs, gameaudio notes, sticky, rockets and fx ground hits. Two bugs were
  found on the way: a ray starting inside a grunt's capsule (fixed with an exclusion filter), and degenerate
  triangles whose NaN distance won the search (lev_5_m3's bridge read as rails). Footstep surfaces now match on
  every level (lev_bonus_m3: 168 `fs_water_shallow` in both).
- Per-grunt voice handles: `audio::Speech` (scream +0xb4c, line +0xb50). There is no second scream while one plays,
  and Dead is refused while a scream plays. A death line stops the line. Hurt and Taunt are kept as the line, and
  the taunt waits for a silent line. The hooks are in ai.rs (scare, think, fire_cycle, die) and topsy.rs.
- oracle_diff.py: ORACLE_OUT, and a loop's variant number is ignored (fire_torch_N_lp).
