## Tooling first

The open items all asked "what code does this in the original": the hook now answers that directly.

- `[test] trace_calls=Name,...` (hook/src/testoracle.cpp): up to 8 HOOK names wrapped; one `call` line per call in
  and.log with frames since load / play frame, the return address, ecx / eax / edx / ebx and three stack arguments
  (`#id` for placed objects, `"text` for strings; pointers probed with VirtualQuery, so no first-chance exceptions).
  Scenarios pass it as `"hook_test"` (tools/oracle_diff.py). HookWrap now stacks wrappers.
- Grunt trace lines carry `kf` (Body_isKeyframed 0x00457790).
- Map a return address to its function with symbols/functions.csv (a 10-line script; the journal's probes lived in
  build/probes, not committed).
