## Learned
- Weapons are not carried between levels: the player object is part of the level (constructed with an empty weapon
  state 0x00461840 / 0x004a0d00, destroyed by the teardown 0x00403940), and 0x00475650 applies the mission's
  player_add_* / set_ammo_* / set_num_*. The player_remove_* flags act on the empty list: no effect. The earlier
  note in remaster-engine.md ("weapons carried over add to it") was wrong.
- Money and the pub intro flags are one banked block (Game+0x570..+0x578 -> +0x57c), restored at every level start
  (0x00401f10) and reset when lev_shell loads (0x00401e80): a restarted level loses what it earned since its start.
- New Game in the original asks for a profile slot and the difficulty first (UiScreen_Activate case 1 ->
  "SaveGame" -> "Difficulty"); not ported.
- Same-named asset-server files are byte-identical across the 24 exports except ui/icons.png (and the json files
  read directly), which made one switchable asset root safe.
