## Done

1. **Reeds black / see-through** (g_lev_4_m3_reeds01_0). Cause: the export had all-zero normals and normalize(0) is
   NaN in the game material. The original does have normals: the reeds are double-sided cards, whose face normals sum
   to zero, and mesh_submeshes rejected the stored normals because those vertices "disagreed". Fixed in the exporter
   (compare only vertices with a face normal); re-exported the four models this changes (reeds, b_grass, grunt_bow_9,
   grunt_arrow_1 in every level that has them; positions, uvs, records identical). The game material now treats a
   zero normal as the original's vertex shader does (N . L = 0: emissive + ambient only, Renderer_UpdateLightConstants
   0x004ff2e0), for the stored-zero ones left (b_beam 8/8, b_grass 12/18, grunt_arrow_1 8/40, a few vertices of
   ~190 other models, listed below). The reeds' emissive is white, so they show the texture at full brightness.
2. **shadow_receive** (object +0x3ec bit 0x10, Object_LoadBaseProps 0x00451360) was ignored: the trees' shadow maps
   darkened and blue-tinted the river (p_water clears it; so do p_grass, p_invisible_walls, p_bigredarrow). level.rs
   `Shadowing { casts, receives }` replaces attach_model's bool; NotShadowReceiver, read by the game material through
   Bevy's mesh flag.
3. **River duller and greyer**: RenderModes_Load 0x00489b40 makes a textured record with flags word +0x34 bit 0x200
   translucent at load (kind |= 0x10), which the stored kind byte lacks; 4_3_water's blend byte is 0, so the original
   *adds* it (0x004897d0 state 0x120, SRCALPHA / ONE). The engine alpha-blended it. Exporter field `translucent`
   (patched into the existing JSONs, json only); MaterialDef::is_translucent / additive; an additive game material is
   AlphaMode::Add in the transmissive pass, composited in gamma space (fxvm/additive.rs). Water patch (strip 20..190 x
   150..172): original mean (66, 73, 60), before (57, 63, 53), after (65, 71, 59); highlights p95 (108, 128, 112),
   before (90, 105, 97), after (118, 138, 124).
4. **Saturation / haze** (item 3): not flatter. Whole-frame mean and saturation match (61, 59, 37) s0.47 vs (60, 58,
   35) s0.47. The Original preset matches the original within ~3 everywhere. The Remaster preset is darker and more
   saturated in the middle distance (mill, wheel ~ -10 %) and less hazy far away (background trees (91, 93, 78) vs
   (113, 119, 108)): fog_modern at density 0.6 gives less haze than the original's linear fog at this range. Not
   changed (a preset-wide choice; see questions).

## Learned

- The stored kind byte is not the run-time kind: check RenderModes_Load for anything the material set-up derives.
- A double-sided card defeats a "stored normals agree with face normals" check.
- `normalize` of a zero vector is NaN on the GPU; Bevy's own mesh_normal_local_to_world guards it, our fragment code
  did not.
