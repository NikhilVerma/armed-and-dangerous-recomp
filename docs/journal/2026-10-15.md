## Effects subsystem port (agent-fx)

Done: the render-fx queue (127 executed functions not cited, 189 with --all) is empty: ported and cited, or in
docs/port/render-fx.csv (75 entries: the game's projected shadows replaced by Bevy shadow maps, decal / pool / class

and tools/engine_map.py now read module folders.

Ported: attach points (0x104 lists: the template's default-anim nodes), the random draws of 0x0f / 0x2f / 0x39 / 0x3a
attach picks, mesh emitters 0x17 / 0x18 / 0x19 / 0x30 / 0x36 / 0x2a (muzzle flash repeats, shell ejection), ground hits

phases and accumulators; the fade drawn), camera path 0x74.

Fixed: particles took the wrong part of their birth frame as their first step; quads are drawn half a move ahead as the
original; a full pool draws no random numbers; a uv scroll with duration 0 now runs forever (it never ran); a
`StartFx` with `Quat::IDENTITY` is unrotated in game space (it laid position-only fx on their side); fx bodies are
sized from their mesh and no longer stop bullets (the shells of the new 0x36 emitters blocked the bot's fire: gunner1
failed until then).

Learned: every fx body is registered on the gravity-scale list (fn_00419020), so a body without 0x11 floats in the
original; the light of a 0.001 s muzzle flash object never reaches the update that would add it (no light in the
original either); the camera-locked CameraFXObject sorts last (+10000); the --fx-test camera no longer parks by the
kegs (the camera port owns the camera now): use the `fx` playtest step and shots.

Tests: 6 playtests (fx_particles, fx_debris, fx_emit, fx_lights, fx_screen, fx_hits) and 19 unit tests (rand, attach
math, emission timing / birth age, cone / lifetime / gravity / drag / shrink, ramp, quads, scale curves, uv ramps,
mesh emitter timer, screen phases / distance fade, curve keys, euler, name picks).

Perf: 4K bench (--background, 25 s with airstrikes and kegs): 60.0 fps average, 53.2 fps 1% low, p99 18.3 ms; a
reference build in the same conditions 60.0 / 49.9 / 19.0 ms: the background window is capped at 60, so the uncapped
