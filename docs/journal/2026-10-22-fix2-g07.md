## Learned

- The scratchpad directory is shared with the other fixers of this wave: use package-specific file names.
- The camera path's `hold` lasts up to 4 s after a path with no text; the player's gates use `path.active()` (the
  original's text pauses the game at the path's end, so the hold never blocks input there).
