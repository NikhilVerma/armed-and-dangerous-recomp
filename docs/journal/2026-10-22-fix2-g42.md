## Learned

- Twiglets made by code have no property block (ObjectSystem_CreateObject's a4 = 0 reaches Twiglet_Slot6's a2): they
  start in state 0 and depend on their maker's 0x0049f380 wake.
- `nav::path` from a dynamic capsule body finds nothing (its own body blocks the start's rays). The twiglets' routes have
  never been used; any walker with a Jolt dynamic body has the same problem.
