# 2026-10-09

## Done
- **AA backends.** DLSS (DLAA) and XeSS run in the 64-bit helper, with FSR as the fallback. The player accepted both
  SDK licences (docs/decision.md). Release packaging: tools/package_release.ps1 builds a binary-only core zip and
  an optional DLSS/XeSS pack with notices.
- **Menu mouse** (qol.md, "Menu cursor, clicks and window capture"):
  - The Windows pointer replaces the sprite in menus.
  - Clicks are hit tested in the pillarboxed 4:3 layout: they used to miss on wide screens.
  - The pointer is clipped to the window while it is in front.
- **Rendering** (remaster-aa.md):
  - AA mip bias -1: sharper at the same stability.
  - Dithered 8-bit output.
  - Alpha coverage for alpha-tested edges. It is active, with no measurable gain on the tested content.
- **Controllers** (qol.md, "Game controllers"): SDL3 3.4.16 with HIDAPI for DS4/DualSense and XInput/WGI for Xbox.
  - The pad state goes into the game's own controller block, plus a third binding column with default bindings.
  - Prompt button names follow the pad type.
  - A scripted virtual pad (`[test] pad_keys`) verified movement, turning, pause, menu navigation and firing.
- Skipped at the player's request: large address aware.

## Learned
- SDL's MSVC cache preseed forces its DirectInput joystick backend on. That backend links dinput8.lib, which is
  this DLL's own name: `SDL_PRESEED OFF` and an empty `HAVE_DINPUT_H`.
- A virtual SDL trigger rests at -32768. At 0 it reads half pressed, and a consumed action never releases.
- visual_capture `--set test.*` used to replace the harness's [test] section (no scenario, endless run). It now
  merges. Also: always pass display.width/height, or the run uses the player's borderless 4K with the cursor clip.
